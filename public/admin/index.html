🚀 Setup Guide

Complete these steps to fully activate your admin dashboard:

  1. ⬜
    Add Firebase Config

    Open public/js/firebase-init.js and replace the placeholder API keys with your Firebase project config. Get it from Firebase Console → Project Settings → Your Apps.

  2. ⬜
    Enable Firebase Auth

    In Firebase Console → Authentication → Sign-in method, enable Email/Password. Then create an admin user in the Users tab.

  3. ⬜
    Create Firestore Database

    In Firebase Console → Firestore Database, create a database and set rules: allow read: if true; allow write: if request.auth != null;

  4. ⬜
    Enable Firebase Storage

    In Firebase Console → Storage, initialize storage with the same auth-based rules as Firestore.
